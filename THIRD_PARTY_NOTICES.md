## OpenSCAD WASM

[`openscad-wasm-prebuilt` 1.2.0](https://github.com/lorenzowritescode/openscad-wasm) is bundled to run OpenSCAD in the browser. Its installed package metadata declares `GPL-2.0-or-later` and includes a copy of the GNU GPL version 2. The `or later` option permits distribution under GPL version 3; SCADlet's root [LICENSE](LICENSE) contains that complete license text.

The corresponding source for the integration is available from its [upstream repository](https://github.com/lorenzowritescode/openscad-wasm). The upstream [OpenSCAD project](https://github.com/openscad/openscad) is the source of the OpenSCAD engine.
